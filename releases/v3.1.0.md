## AgentDesk v3.1.0

> 你的助理开始"记得你"了！本次更新带来个人长期记忆系统，助理能够跨会话记住你的偏好与项目约定；同时引入项目工作区，让会话、文件与运行环境围绕项目组织，并支持真实 Python 本地执行与连续对话队列。

---

### 🚀 新功能

#### 🧠 个人长期记忆

- **自动学习** — 对话结束后自动提炼值得长期记住的偏好与事实，经过敏感信息过滤、原文证据校验后才会入库
- **记忆召回** — 发起对话时自动召回相关记忆注入上下文，消息下方可查看本轮实际使用了哪些记忆
- **对话内管理** — 直接对助理说"记住…"即可显式保存，也可让助理查询、修改或删除已有记忆
- **记忆管理页** — 设置中新增记忆管理，支持查看、编辑、置顶、单条删除与按范围清空，并可查看后台学习任务状态
- **无记忆模式** — 支持单轮临时无记忆发送与会话级无记忆模式，敏感对话不留痕；关闭全局记忆后召回与学习全部停止
- **项目范围记忆** — 记忆区分个人偏好与项目事实，项目记忆仅在对应项目的会话中生效，删除项目时同步清理

#### 📁 项目工作区

- **项目与会话绑定** — 会话可归属到项目，侧边栏按项目组织会话列表
- **项目级上下文** — 项目的目录结构、运行环境等信息自动注入对话，助理可感知当前工作区状态
- **历史会话搜索** — 助理可检索当前项目的历史会话内容，跨会话延续工作（遵循记忆开关与无记忆模式限制）

#### 🐍 本地运行增强

- **真实 Python 执行** — 本地运行集支持调用系统 Python 环境执行代码，不再局限于浏览器内沙盒
- **连续对话队列** — 助理回复过程中可继续输入，消息自动排队依次处理

#### 🛠 技能中心

- **接入魔搭社区** — 技能中心可浏览并安装魔搭社区（ModelScope）的技能包，扩展助理能力更方便

---

### ✨ 体验优化

- 重新生成回答时自动沿用该轮原有的记忆模式，不会意外读取或学习记忆
- 记忆冲突时保留旧记忆并标记待确认，由用户决定取舍，不会静默覆盖
- 清空记忆时同步取消进行中的后台学习任务，删除的内容不会被重新写回
- 会话删除、消息回退时级联失效对应来源的记忆，来源全部失效的记忆自动退休
- 记忆指示器展示召回状态与命中条数，学习过程对用户透明

---

### 🐛 问题修复

- 修复切换无记忆模式后，此前召回的记忆文本仍残留在助理上下文中的问题
- 修复自动学习可能收录假设、转述或与原文相反内容的问题（如否定被改写为肯定、数字被臆造）
- 修复被拒绝的学习候选残留在记忆服务中的问题，失败清理由定时任务补偿
- 修复会话未绑定项目时发起对话报错的问题
- 修复本地沙盒运行的若干稳定性问题

---

### 🔧 工程化改进

- 新增记忆领域模型：记忆条目、来源溯源、修订历史、使用事件与后台学习任务（outbox 模式，幂等 + 乐观锁 + 租约恢复）
- Mem0 仅作为候选抽取适配器，PostgreSQL 为记忆唯一事实源，拒绝候选双向清理保证最终一致
- Agent 状态支持从原始消息重建，保证无记忆模式下上下文不含任何记忆增强文本
- 补充记忆策略、任务竞态、历史搜索范围等 60+ 自动化测试

> 自行部署后端的用户升级前请依次执行 `backend/src/main/resources/db/migration-project-runtime.sql`、`migration-skill-packages.sql` 与 `migration-memory-system.sql`。现有聊天消息、知识库、技能和设置数据不会被删除。启用自动记忆需配置 `MEM0_*` 环境变量（可选，未配置时仅手动记忆可用）。
