## AgentDesk v1.2.0

> 新增应用内自动升级功能！从此无需手动下载安装包，一键检查更新、下载、安装重启。

---

### 🚀 新功能

#### 🔄 应用内自动升级
- **检查更新** — 在设置页点击"检查更新"，自动对比 GitHub Releases 上的最新版本
- **下载更新** — 发现新版本后一键下载，实时显示下载进度（百分比、速度、已下载/总大小）
- **安装重启** — 下载完成后确认安装，应用自动重启并完成升级
- **CI 自动发布** — 推送 tag 后 GitHub Actions 自动构建并发布安装包，支持增量更新（blockmap）

#### 💬 聊天头像
- 对话界面新增用户和 AI 头像显示，聊天体验更直观

---

### ✨ 体验优化

- **配置自动保存** — 设置页面修改后自动保存，无需手动点击保存按钮
- 前端代码整理，提升整体代码质量

---

### 🔧 工程化改进

- 引入 `electron-updater` 实现桌面端自动更新
- `electron-builder.yml` 配置 GitHub 作为更新发布源
- CI 流水线增加 `latest.yml` 和 `.blockmap` 文件上传，支持增量更新检测
- 新增 `dev-app-update.yml` 支持开发环境调试更新流程
- 版本号从 v1.1.1 升至 v1.2.0
