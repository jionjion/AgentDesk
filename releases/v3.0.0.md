## AgentDesk v3.0.0

> 专家团协作正式升级！本次更新引入全新的多智能体架构，让首席助理能够按任务需要调度不同领域专家，并实时展示专家执行状态与任务进度。

---

### 🚀 新功能

#### 🤖 多智能体专家团

- **智能任务委派** — 首席助理可根据任务类型自动调度研究员、软件工程师、代码审查员、数据分析师、专业写作者、知识管理员和系统操作员
- **专业分工协作** — 每位专家拥有独立的角色提示词和工具权限，复杂任务可由多个专家协同完成
- **更安全的工具使用** — 专家仅能访问职责所需的工具，本机命令继续沿用风险识别与用户审批机制

#### 👀 专家执行状态

- **专家团状态栏** — 对话中实时显示正在工作的专家及整体完成进度
- **执行详情展开** — 可查看每位专家的思考过程、工具调用和输出内容
- **任务进度同步** — 计划创建、任务更新与完成状态实时同步到现有任务面板

#### 🧠 会话状态与记忆

- **会话状态持久化** — Agent 状态按用户和会话独立保存，重启后可继续原有上下文
- **长期记忆接入对话** — 启用 Mem0 后，对话会自动召回相关记忆，并在任务完成后沉淀新的信息
- **技能偏好生效** — Agent 只会加载用户已启用的内置技能和自定义技能

---

### ✨ 体验优化

- 子智能体输出独立展示，不再混入主助理的最终回复
- 工具调用参数会在聚合完整后显示，减少空参数和不完整信息
- “重新生成”会正确回退后续消息与旧状态，避免不同回答分支相互干扰
- 长任务中断更加精准，不会误创建或中断其他会话的 Agent
- 定时任务已适配新的 Agent 运行时，执行结束后自动释放资源
- 优化模型停止原因、权限拒绝、数据结果和最大迭代次数等状态提示

---

### 🐛 问题修复

- 修复多用户、多会话场景下 Agent 状态可能相互影响的问题
- 修复子智能体事件影响主对话状态的问题
- 修复部分工具参数解析不完整的问题
- 修复远程命令执行、文件处理和接口调用中的多处安全与稳定性隐患
- 修复 AgentScope 与 Mem0 依赖版本冲突导致的运行时异常
- 加强 Markdown 内容清理，降低不安全内容渲染风险

---

### 🔧 工程化改进

- Agent 运行时升级至 AgentScope Java v2，采用 Harness 原生子智能体架构
- 新增统一的 Agent 事件桥接层，完善 SSE 事件协议与子智能体事件隔离
- 新增 PostgreSQL v2 状态存储，按用户、会话和状态键进行隔离
- 补充多智能体、任务进度、状态持久化、权限校验等自动化测试
- 引入 Maven Wrapper，统一后端构建与测试环境
- 后端最低 Java 版本统一为 Java 21

> 自行部署后端的用户升级前请执行 `backend/src/main/resources/db/migration-v2.sql`，创建 AgentScope v2 状态表。现有聊天消息、知识库、技能和设置数据不会被删除。
