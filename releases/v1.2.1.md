## AgentDesk v1.2.1

> 应用内自动更新体验全面升级！同时后端代码结构完成重构，为后续迭代打下更坚实的基础。

---

### 🚀 新功能

#### 🔄 自动更新体验升级
- **界面重新设计** — 版本信息与"检查更新"按钮合并到顶部卡片，状态一目了然
- **分级卡片展示** — 发现新版本、下载进度、下载完成分别用绿色、默认、蓝色卡片呈现，视觉层次更清晰
- **下载进度更直观** — 右侧百分比数字独立展示，进度条动画过渡更平滑
- **支持增量更新** — 安装包发布时同步产出 `.blockmap` 文件，自动更新仅下载差异部分，流量更省、速度更快

#### 📚 在线文档站点
- **GitHub Pages 自动部署** — 每次发版自动将项目文档站点同步到线上，访问更方便

---

### ✨ 体验优化

- 自动更新状态切换更顺畅，从"检查中 → 发现新版 → 下载 → 重启安装"流程连贯
- 视觉风格统一到全新的卡片化布局，深色模式下配色更协调

---

### 🐛 问题修复

- 修复开发模式下自动更新配置文件路径解析错误的问题

---

### 🔧 工程化改进

- **后端包结构重构** — Agent 层拆分为 `core` / `hook` / `tool` 三个子包，DTO 按业务领域（认证、聊天、文件、记忆、模型、会话、设置、技能、定时任务）分包管理，代码可读性和可维护性大幅提升
- **实体类独立归集** — 将实体类从各业务模块移至统一的 `entity` 包，符合分层规范
- **服务层归一** — `SessionService` 等统一收敛到 `service` 包
- **启动引导独立** — `StartupRunner` 迁移到独立的 `bootstrap` 包
- **清理无用代码** — 移除不再使用的 `AgentConfig` 类
- 基于 Electron 33 + Vue 3 + TypeScript 构建桌面应用
- 后端采用 Spring Boot 3 + Java 21 + JPA 架构
- 版本号从 v1.2.0 升至 v1.2.1
