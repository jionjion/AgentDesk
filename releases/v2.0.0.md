## AgentDesk v2.0.0

> 全面升级为智能 Agent 平台！新增六大子代理能力、RAG 知识库、MCP 协议集成、技能包系统，打造真正的 AI 桌面助手。

---

### 🚀 新功能

#### 🤖 子代理体系

- **互联网检索** — 联网搜索实时信息，自动整理摘要返回
- **深度检索** — 多轮深入搜索，适合复杂问题的全面调研
- **代码评审** — 基于 qwen3-coder-plus 模型，对代码片段进行专业审查
- **翻译** — 多语言互译，保留原文格式与语义
- **摘要** — 长文本智能提炼，快速获取核心要点
- **计划** — 任务拆解与执行计划生成，辅助项目规划

#### 📚 RAG 知识库

- 支持上传 PDF / DOCX / TXT / Markdown 文档
- Tika 解析 + 智能分块 + DashScope 向量化
- 基于 pgvector 的语义检索，对话中自动引用相关知识

#### 🔌 MCP 协议集成

- 动态连接外部 MCP 服务器，扩展 Agent 工具能力
- 可视化管理 MCP 服务器配置（添加、启用、禁用）

#### 🧰 技能包系统

- 内置技能：编程助手、数据分析、文件解析、写作助手
- 支持 ZIP 技能包一键安装与管理
- Agent 核心集成 SkillBox，按需激活技能

#### 🌐 更多工具

- **IP 定位** — 获取当前网络 IP 的地理位置信息
- **Obsidian 知识沉淀** — AI 价值判断后自动导出对话精华到 Obsidian

#### 💬 对话体验

- 聊天对话框右侧新增对话导航栏，快速跳转历史消息
- 对话框效果全面优化，布局更合理

---

### ✨ 体验优化

- 前端 UI 主题配色升级为品牌紫，视觉风格统一
- 聊天通信从 SSE Source 改为 Fetch 调用，连接更稳定
- 聊天提问气泡支持换行显示
- 设置页面全面改版，功能分区更清晰
- IPC 新增目录选择能力
- SSE 连接中断处理优化

---

### 🐛 问题修复

- 修复归档功能自动触发的问题，改为手动控制
- 修复登录功能缺少"记住我"选项的问题
- 修复设置界面多处细节问题
- 修复版本号尾缀不统一的问题

---

### 🔧 工程化改进

- Agent 核心重构：集成 SkillBox 技能系统
- 子代理以 "Agent as Tool" 模式注册，架构更灵活
- 子代理 prompt 模板使用 FreeMarker（`.ftl`）管理
- 代码注释补充完善
- 基于 Electron 33 + Vue 3 + TypeScript 构建桌面应用
- 后端采用 Spring Boot 3 + Java 21 + AgentScope 框架
