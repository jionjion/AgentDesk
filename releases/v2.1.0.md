## AgentDesk v2.1.0

> 进一步增强 Agent 能力！新增沙箱代码执行、远程工具调用、批量检索代理，让 AI 不仅能说，还能真正动手执行。

---

### 🚀 新功能

#### 🖥️ 代码沙箱（Sandbox）

- **Python 代码执行** — 支持在隔离环境中运行 Python 代码，安全执行数据分析、文件处理等任务
- **完整 Python 运行时** — 基于 Pyodide，支持大部分 Python 标准库
- **结果可视化** — 代码输出结果直接在对话中展示，包括图表和文本

#### 🔧 远程工具调用

- **远程命令执行** — Agent 可调用远程服务器的命令行工具
- **批量执行** — 支持一次性执行多条命令，自动汇总结果
- **安全校验** — 命令执行前需用户确认，防止误操作

#### 🤖 代理增强

- **批量检索代理** — 同时对多个主题进行检索，快速对比信息
- **自定义创建代理工具** — 根据需求动态创建专用子代理

#### 💓 稳定性提升

- **心跳检测** — 实时监控连接状态，自动重连保证对话不中断
- **扩展 MCP 支持类型** — MCP 协议支持更多工具类型
